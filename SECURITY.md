# Security Policy

## Supported versions

Only the latest version on the `main` branch is currently supported with security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory flow for this repository, or contact the maintainers privately through the repository owner account.

Include the affected file or feature, reproduction steps, impact, and a suggested mitigation when available. Please avoid sharing credentials, private board content, or other sensitive data in the report.

We will acknowledge reports as soon as practical and coordinate disclosure after a fix or mitigation is available.
